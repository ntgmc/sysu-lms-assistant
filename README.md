# 🎓 中山大学 LMS 助手 (SYSU LMS Assistant)

[![JavaScript](https://img.shields.io/badge/Language-JavaScript-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![Tampermonkey](https://img.shields.io/badge/Extension-Tampermonkey-black.svg)](https://www.tampermonkey.net/)
[![Version](https://img.shields.io/badge/Version-2.1.0-blue.svg)](#)

这是一个为中山大学 LMS 编写的浏览器用户脚本。它将视频自动播放、自动下一页、进度修复、讨论任务自动完成和可选计时加速整合在一个脚本中，并通过统一控制面板管理所有功能。

## 🚨 风险警示

计时加速会修改资源停留页创建的浏览器计时器，可能产生异常学习数据，并可能违反学校或平台的使用规定。由此可能造成进度清零、账号异常或其他后果。

- 加速功能在新版中默认关闭，必须由用户在控制面板中明确开启。
- 开启、关闭或改变倍率时，脚本会再次提示风险，并在确认后刷新当前页面。
- 讨论任务自动完成会真实发表回复，内容对教师和同学可见且通常无法撤销；该功能同样默认关闭。
- 请只在法律、学校规章和平台规则允许的范围内使用。

## ✨ 功能

### 学习辅助

- **自动播放与防暂停**：进入视频页面后尝试静音播放，并在意外暂停时恢复。
- **自动下一页**：课程完成后进入下一项活动。
- **进度修复**：视频播放结束但 LMS 进度未满时自动重播。
- **自动超清**：检测到视频画质菜单后尝试选择“超清”。
- **讨论任务自动完成**：检测“发表论坛帖子”要求，自动回复并验证完成状态；失败时停止，避免重复发帖。

### 统一控制面板

- 右下角状态胶囊显示助手当前状态，点击后展开完整设置。
- 支持总开关、自动播放、自动下一页、自动超清和讨论任务自动完成开关。
- 支持用 `|` 分隔自定义回复候选，并从当前页普通帖子中随机选择回复目标和内容。
- 支持 `2×`、`5×`、`10×`、`25×` 和 `50×` 五档计时加速预设。
- 设置跨页面保存在浏览器本地，不上传数据，也不包含遥测。
- 支持键盘操作、明暗主题、减少动态效果和屏幕阅读器通知。

### 可选计时加速

- 仅在 `/mod/fsresource/view.php` 资源停留页生效，其他 LMS 页面不会修改计时器。
- 加速器和助手内部计时相互隔离，不会缩短控制面板提示、页面检测或自动跳转的等待时间。
- 页面已经创建的计时器不能可靠地实时改速，因此修改加速设置后必须刷新。

## 🛠️ 安装

### 第一步：安装用户脚本管理器

请先安装 [Tampermonkey](https://www.tampermonkey.net/)（推荐）或 [Violentmonkey](https://violentmonkey.github.io/)。

### 第二步：安装统一脚本

[👉 点击安装中山大学 LMS 助手](https://raw.githubusercontent.com/ntgmc/sysu-lms-assistant/main/lms-script.user.js)

从 2.0.0 开始只需安装 `lms-script.user.js`。不要再单独安装 `time-hacker.user.js`。

### 从旧版本迁移

仓库仍保留 `time-hacker.user.js`，但它现在只是迁移兼容脚本，不再修改计时器。已安装旧加速器的用户在自动更新后会看到一次统一脚本安装提示。

如果你的脚本管理器长期没有更新旧版 `time-hacker.user.js`，请在安装 2.0.0 前手动禁用或卸载旧脚本。旧版加速器与统一脚本同时运行可能重复包装页面计时器，导致倍率异常。

## 🚀 使用指南

1. 安装脚本后登录 `lms.sysu.edu.cn` 并进入课程。
2. 页面右下角出现“LMS 助手”状态胶囊，表示统一脚本已加载。
3. 点击状态胶囊展开控制面板，可即时修改普通自动化设置。
4. 如需自动完成讨论任务，在控制面板中填写回复模板并明确开启对应开关。默认模板为 `同意|赞同|支持`，半角竖线两侧的非空内容会成为随机候选。
5. 讨论任务未完成时，脚本随机选择当前页的一条普通帖子回复；没有普通帖子时回退到主题首帖。平台确认完成后，是否继续下一页由“完成后自动下一页”控制。
6. 若提交或完成验证失败，脚本不会自动重复发帖；请检查页面后点击控制面板中的“重试讨论任务”。
7. 如需使用计时加速，在“计时加速”区域开启功能并选择倍率。
8. 点击“应用并刷新”，阅读风险提示后确认；页面刷新后新倍率才会生效。
9. 如需手动答题或操作，可关闭总开关暂停全部自动化，控制面板仍保持可用。

控制面板可通过键盘访问。按 `Esc` 可以收起面板，状态和设置不会丢失。

## ⚙️ 默认设置

| 设置 | 默认值 |
| :--- | :--- |
| LMS 助手总开关 | 开启 |
| 自动播放与防暂停 | 开启 |
| 完成后自动下一页 | 开启 |
| 自动切换超清 | 开启 |
| 自动完成讨论任务 | **关闭** |
| 随机回复模板 | `同意\|赞同\|支持` |
| 计时加速 | **关闭** |
| 加速倍率 | 10× |

旧版主脚本使用的 `lms_script_running` 状态会自动迁移，总开关也会继续同步这个旧设置键，便于必要时回退。

## 📝 更新日志

### 2.1.0

- 将“自动跳过讨论页”替换为默认关闭的讨论任务自动完成功能。
- 新增 `|` 分隔的可编辑随机回复模板、候选计数和输入校验。
- 复用 Moodle 原生回复页面和表单，不直接调用私有接口或拼装会话请求。
- 新增跨页防重复状态、完成徽章验证、单次刷新确认和显式重试流程。
- 优先随机回复普通帖子，没有普通帖子时回退主题首帖。

- 新增 Shadow DOM 统一控制面板、状态显示、设置持久化和无障碍交互。
- 加速功能改为默认关闭，并增加倍率预设、风险确认和刷新应用流程。
- 隔离助手内部计时器，避免 Toast、轮询和跳转延迟被页面加速器缩短。
- 优化视频事件绑定、重复提示、页面状态反馈和错误恢复。
- 将旧 `time-hacker.user.js` 改为无计时器钩子的迁移兼容脚本。

- 优化资源停留页的定时器加速逻辑。
